# mahlzeit-site

Static pages for the Mahlzeit iOS app, served by GitHub Pages from `main` (root).

- `/` marketing · `/privacy/` · `/support/` · `/impressum/`
- `/share/#<token>`, `/join/#<token>` — deep-link landing pages (copied from the app repo's `docs/landing/`)

Before publishing: replace every `class="todo"` placeholder (`grep -rn todo --include=*.html .`).
